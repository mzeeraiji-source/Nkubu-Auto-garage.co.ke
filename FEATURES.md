# Nkubu Auto Garage — Feature Recommendations and MVP Priorities

This file captures the recommended feature set for the project and the priority order for delivery.

## 1) High-priority features for launch

### Online booking form
- Service selection
- Vehicle details
- Date and time picker
- Customer notes
- Photo upload support
- Plate number entry
- Phone number capture
- Auto-confirm booking when a slot is free

### WhatsApp-first support
- Pre-filled WhatsApp links for quote requests
- Quick contact flow for common support cases
- Option to tag chats as quote request, booking inquiry, or service issue

### Service catalog
- Service names and durations
- Service detail pages
- “Request quote” actions instead of public pricing
- Strong focus on diesel, hydraulics, electrical, and diagnostics

### Contact and location page
- Exact address
- Phone number
- Opening hours
- Map link
- Route button
- Clear workshop accessibility info

### FAQ and chatbot support
- English and Swahili responses
- Common workshop questions
- Service and booking support
- Human handoff when the answer is unclear

### Mobile-first UX
- Large tap targets
- Sticky bottom mobile tab bar
- Fast loading for low-end Android devices
- Responsive layout for 360px screens

### Offline-friendly support
- Home, services, FAQ, and contact should still load with limited connectivity
- Booking and diagnostics pages should fall back gracefully with clear instructions on unsupported browsers

## 2) Features that add strong value

### Vehicle history management
- Save a customer’s vehicles
- Store service history
- Track repair notes and recurring problems
- Support maintenance reminders by date or mileage

### Pick-up and drop-off requests
- Request vehicle collection or return
- Schedule for customers who cannot drive in

### Reminder system
- 24-hour reminder
- 2-hour reminder
- Email, push, or WhatsApp reminders
- Service-due reminders based on date or mileage

### Parts inventory management
- Parts catalog
- Stock tracking
- Low-stock alerts
- Out-of-stock flags on the public site

### Quote request flow
- Quote request form
- Photo upload for issue context
- No automatic public prices
- Staff review and approval flow

### Review system
- Request review after a completed booking
- Moderate reviews before publication
- Flag abusive or inappropriate content

### Fleet / business accounts
- Repeat vehicle tracking for matatus and business customers
- Corporate service booking flows
- Business account summaries

## 3) Business-focused recommendations

### Loyalty and referral program
- 1 point per KES 100 spent
- 100 points = KES 100 off
- Referral discount for both parties
- Clear admin tracking of earned and redeemed points

### Corporate / fleet support
- Multi-vehicle bookings
- Business invoice support
- Priority scheduling for repeat clients

### Local marketing pages
- About page
- Gallery page
- Tips and maintenance articles
- Careers page
- Testimonials and customer stories

### Local SEO and trust-building
- Google Business Profile setup
- Local keyword optimization
- Location-specific landing pages
- Trust-building content and workshop photos

## 4) Operational recommendations

### Admin panel core modules
- Bookings
- Customers
- Vehicles
- Services
- Parts stock
- Chat escalations
- Settings
- Basic analytics

### Analytics to add early
- Bookings today
- Weekly summary
- Most requested services
- Revenue summary

### Audit trail
- Track booking changes
- Track admin actions
- Track login events and security actions
- Maintain logs for safety and future support

### Queue-based agent design
- Booking reminder agent
- Support escalation agent
- Health check agent
- Future agents can be added without rewriting the system

## 5) Features to avoid for now

- Full advanced AI diagnostics before the basic booking flow works
- Paid SMS gateway before demand is proven
- Automatic WhatsApp sending without a paid or approved channel
- Full payment flow before core booking and support is stable
- Heavy autoplay video background
- Expensive third-party tools that are not necessary for launch

## 6) Best MVP recommendation

The best MVP for Nkubu Auto Garage should include the following and build in this order:

1. Home page
2. Services page
3. Booking page
4. Contact page
5. FAQ / support chat
6. WhatsApp CTA
7. Admin booking dashboard
8. Customer vehicle profiles
9. Reminder emails and push notifications
10. Local SEO and trust pages

This gives the business a real operational tool quickly without overbuilding too early.

## 7) Delivery recommendation

Recommended launch order:
- Phase 1: core public site + booking flow
- Phase 2: customer account + vehicle history + reminders
- Phase 3: help/chat + FAQ escalation + admin tools
- Phase 4: loyalty, fleet, and parts inventory
- Phase 5: analytics, deeper automation, and optimization

## 8) Final recommendation

The strongest product direction is:
- mobile-first
- quote-based instead of price-first
- WhatsApp-first support
- simple admin dashboard
- local trust-building and visible service quality
- low-overhead automation with room to grow

This is the right balance for a Kenyan garage business serving local customers and building trust before scaling aggressively.
